below was not started or not finished.

### How to restart

1. Rebuild the validation toolchain (outside the repository):
   `bash scripts/bootstrap-toolchain.sh && source ~/.cache/academy-tools/env.sh`
2. Read [`templates/AUTHOR-GUIDE.md`](templates/AUTHOR-GUIDE.md) and
   [`templates/CONVENTIONS.md`](templates/CONVENTIONS.md) — every new file follows them.
3. Apply the [pending corrections](#pending-corrections-to-the-verification-matrix) to the
   verification matrix first, so new chapters start from corrected facts.
4. Work through the queue below in order. Each item names the files to write.
5. After each batch: `bash scripts/validate-all.sh`, then commit.
